# مجلد الخطوط

ضع هنا خطاً عربياً بصيغة TTF باسم `arabic.ttf`

## خطوط عربية مجانية موصى بها

1. **Cairo** - حديث وأنيق
   https://fonts.google.com/specimen/Cairo
   
2. **Tajawal** - واضح ومناسب للعناوين
   https://fonts.google.com/specimen/Tajawal

3. **IBM Plex Sans Arabic** - احترافي
   https://fonts.google.com/specimen/IBM+Plex+Sans+Arabic

4. **Almarai** - جميل للنصوص الإخبارية
   https://fonts.google.com/specimen/Almarai

## طريقة الاستخدام

1. حمّل أي خط من الروابط أعلاه
2. اختر الوزن المناسب (Bold للعناوين عادةً)
3. أعد تسمية الملف إلى `arabic.ttf`
4. ضعه في هذا المجلد

## مثال أوامر بعد التحميل

```bash
# مثلاً لخط Cairo Bold
mv ~/Downloads/Cairo-Bold.ttf fonts/arabic.ttf
```
