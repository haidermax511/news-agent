# قوالب التصميم (Templates)

ضع في هذا المجلد 4 صور قوالب (إطارات) خاصة بكل صفحة:

```
page1_general.png    -> إطار صفحة الأخبار العامة
page2_politics.png   -> إطار صفحة السياسة
page3_sports.png     -> إطار صفحة الرياضة
page4_economy.png    -> إطار صفحة الاقتصاد
```

## مواصفات القالب الموصى بها

- **الأبعاد**: 1080 × 1080 بكسل (مربع - مناسب لانستغرام وفيسبوك)
- **الصيغة**: PNG
- **اترك مساحة فارغة** في المنتصف أو الأسفل لإضافة نص العنوان عليها
- **اللوقو والإطار** يكونان مدمجين في القالب نفسه

## كيفية إنشاء القوالب

### الخيار 1: Canva (مجاناً)
1. ادخل canva.com
2. أنشئ تصميماً بحجم 1080×1080
3. صمم الإطار، الشعار، الألوان الخاصة بالصفحة
4. اترك المنطقة المخصصة للنص فارغة (أو ضع placeholder)
5. صدّر الصورة بصيغة PNG

### الخيار 2: Photoshop / GIMP
- نفس المنطق - صمم القالب واترك مساحة للنص

## ضبط موضع النص

عدّل ملف `config/pages.json` لتحديد:
- `title_position`: [x, y] إحداثيات مركز العنوان
- `title_size`: حجم الخط
- `title_color`: لون الخط (هيكس)
- `subtitle_position`: موضع النص الفرعي
- إلخ...

## مثال

إذا كان قالبك يحتوي على شريط أزرق في الأسفل تريد كتابة العنوان عليه:

```json
"design": {
  "title_position": [540, 850],
  "title_size": 50,
  "title_color": "#FFFFFF",
  "title_max_width": 950,
  "title_align": "center"
}
```
